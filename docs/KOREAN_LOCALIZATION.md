# FSU 한국어 지원 설계

## 목표

EA Web App의 언어와 별개로 FSU가 추가한 설정, 버튼, 알림, 선수 정보, SBC 기능을 영어 또는 한국어로 표시할 수 있게 한다.

## 설정 위치와 동작

`홈 → FSU 설정(FSU Configuration) → 표시 언어`에서 다음 값을 선택한다.

| 설정 | 동작 |
|---|---|
| `자동(EA)` | EA Web App이 한국어면 FSU도 한국어, 중국어면 해당 중국어, 그 외에는 영어 사용 |
| `English` | EA Web App 언어와 관계없이 FSU 영어 사용 |
| `한국어` | EA Web App 언어와 관계없이 FSU 한국어 사용 |

선택값은 Tampermonkey 저장소의 기존 `set` 객체 안에 `language` 필드로 보관한다. 언어를 바꾸면 저장 완료 알림을 표시하고 약 700ms 뒤 Web App을 다시 불러와 이미 생성된 모든 FSU 화면에도 같은 언어를 적용한다.

기존 설치에 `language` 값이 없거나 알 수 없는 값이 저장되어 있으면 `자동(EA)`로 마이그레이션한다.

## 내부 언어 인덱스

기존 배열형 번역 구조를 유지한다.

```text
0: 중국어 간체
1: 중국어 번체
2: 영어
3: 한국어
```

한국어 사전은 원본 번역 키와 동일한 키 집합으로 관리하고 초기화 시 각 번역 배열의 네 번째 값으로 연결한다. 한국어 값이 누락된 비정상 빌드에서는 영어 값을 대체 표시해 버튼이나 메시지가 `undefined`로 나오지 않게 한다.

## 번역 범위

현재 FSU가 관리하는 615개 문자열 키를 모두 포함한다.

- FSU 설정과 표시 옵션
- 가격, 선수 카드, 중복 선수, SBC Storage
- Club의 `My Players` 필터와 선수 상세 팝업
- 진화 선수 선택기
- 빠른 SBC 제출안, Fill/Submit 상태와 오류 메시지
- SBC, 스쿼드 빌더, 팩, 목표, 알림
- 선수 체형과 실제 얼굴 정보

`EA ID`, `OVR`, `PS+`, `SBC`, `English`처럼 제품명 또는 게임에서 통용되는 약어는 번역하지 않는다.

## 안전 규칙

- `%1`, `%2` 같은 동적 자리표시자의 번호와 개수를 영어 원문과 동일하게 유지한다.
- HTML이 포함된 안내문은 태그를 보존한다.
- 저장된 언어 설정을 로그인 초기화와 설정 화면 생성 전에 적용한다.
- 알 수 없는 번역 키는 키 문자열 자체를 표시하는 기존 동작을 유지한다.
- 언어 선택 버튼은 좁은 모바일에서도 세 열을 유지하고 최소 44px 터치 높이를 제공한다.

## 진화 이름의 EA 공식 영어 병기

진화 이름은 FSU 사전으로 번역하지 않는다. EA Web App이 반환한 현재 언어 이름과 진화 슬롯 ID를 보존하고, 먼저 EA의 공식 영어 현지화 파일에 있는 `AcademySlot{슬롯 ID}` 값을 연결한다. 최신 슬롯이 정적 파일에 없으면 영어로 접속한 EA Web App의 실제 진화 API 응답에서 같은 슬롯 ID의 `slotName`을 저장해 사용한다.

```text
현재 언어의 slotName
  + 동일 슬롯 ID의 EA en-US AcademySlot 값
  = 현재 언어명 (EA 공식 영어명)
```

- 공식 출처: `https://www.ea.com/ea-sports-fc/ultimate-team/web-app/loc/en-US.json`
- EA 화면이 이미 영어이거나 두 이름이 같으면 한 번만 표시한다.
- 공식 영어 키가 없는 최신 진화는 EA Web App 언어를 `English`로 바꾸고 진화 화면을 한 번 열면, 해당 영문 응답을 슬롯 ID별로 저장한다. 그 뒤 EA 언어를 한국어로 되돌리면 병기된다.
- 위 절차에서 바꾸는 것은 **EA Web App 언어**다. FSU Configuration의 `표시 언어`는 FSU 버튼과 알림 언어만 바꾸므로 영문 진화 이름 수집에는 영향을 주지 않는다.
- 공식 영어 키가 없고 영어 EA 응답도 아직 저장하지 못했거나 파일을 불러오지 못하면 현재 언어 이름만 유지한다. 이 경우 진화 화면에서 한 세션에 한 번 동기화 안내를 표시한다.
- 네트워크 요청과 모바일 JSON 파싱을 줄이기 위해 정적 카탈로그는 6시간 캐시하고, 실제 EA 영어 응답에서 확인한 이름은 별도 보존한다.
- 캐시·응답 값은 숫자 슬롯 ID, 문자열 이름, 최대 길이를 검사한 뒤 사용한다.
- 같은 슬롯 객체를 여러 번 렌더링해도 괄호가 중복되지 않게 원래 이름과 표시 이름을 별도로 추적한다.

따라서 `완전한 영광 (Total Glory)` 같은 표시는 EA가 해당 슬롯 ID에 `Total Glory`를 실제로 제공할 때만 생성된다. FSU가 한국어 이름을 영어로 기계 번역하는 대체 경로는 두지 않는다.

## 검증

- 원본 키 615개와 한국어 키 615개의 일대일 일치
- 누락 키, 추가 키, 중복 키가 없는지 검사
- 영어와 한국어의 `%n` 자리표시자 집합 일치
- 자동 모드에서 EA 한국어 → FSU 한국어, EA 중국어 → 기존 중국어, 그 외 → 영어 선택
- 영어·한국어 강제 설정이 EA 언어와 독립적으로 적용되는지 검사
- 360×720, 412×915, 768×720 화면에서 언어 버튼 높이 44px 및 가로 넘침 없음
- 비영어 EA 언어에서 서로 다른 공식 영어명이 괄호로 한 번만 붙는지 검사
- 영어 EA 언어, 같은 이름, 누락 키, 네트워크 실패에서는 기존 이름이 그대로인지 검사
- 영어 EA 세션에서 최신 슬롯 이름을 저장한 뒤 한국어 EA 세션에서 같은 슬롯 ID에 병기되는지 검사
